# Coupon tray: bappzaar master → kit

Screen `cart/couponTray` (sheet, `floating`: master passes `isFloating` true to `useScrollToClose`, so `OverlayBottomSheet` floats 12 px in, r16, with the #B7B7B7 handle 18 px above). Opened by the cart's **View available coupons & offers** row (`CouponInput`), as master's `NoonCartScreen.onAvailablePress` does when `FeatureFlags.isCouponTrayRevampEnabled()` (`coupon_tray_revamp` / `coupon_tray_revamp_with_catalog` = 1). The legacy tray (`NoonCouponTrayOverlayScreen`, flag off) is not ported. Read from `origin/master` (read-only), values resolved from `NoonColors.ts`, copy from `noon-en.json`.

Codes that apply are in `cartCoupons` (`src/kit/DemoStore.tsx`).
